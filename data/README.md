# Data Directory

Place your source documents here for ingestion:

## Files

- `dpa-2012.pdf` - Data Privacy Act of 2012 (Republic Act No. 10173)
- `dpa-irr-2016.pdf` - Implementing Rules and Regulations (2016)
- Other PDF documents for ingestion

## Usage

After placing PDF files here, run the corresponding ingestion script:

```bash
# For DPA PDF
npm run ingest:dpa-pdf
```

## Download Sources

- **DPA 2012**: https://www.privacy.gov.ph/data-privacy-act/
- **IRR 2016**: https://www.privacy.gov.ph/implementing-rules-and-regulations/
- **NPC Circulars**: https://www.privacy.gov.ph/advisories/
